# 使用說明書

這份說明書教你從安裝到看懂結果。所有計算都在你自己的電腦上進行，聊天記錄不會上傳。

## 1. 安裝與開啟

下載連結在[首頁](../README.md)。

| 系統 | 做法 |
|---|---|
| Windows 10 / 11 | 執行 `ChatRelationshipReport-Windows-Setup.exe`，照畫面按「下一步」。可勾選桌面捷徑。 |
| macOS | 開啟 `.dmg`，把 App 拖進「Applications」。Apple 晶片（M1 以後）選 arm64，舊款 Intel 機型選 intel。 |

**第一次開啟會看到安全警告**，因為安裝檔沒有付費的程式碼簽章，這是預期的。
- Windows：出現藍色 SmartScreen 畫面時，點「其他資訊」→「仍要執行」。
- macOS：在 App 上按右鍵 →「打開」。若仍被擋，在終端機執行 `xattr -cr /Applications/ChatRelationshipReport.app`。

想確認檔案沒被改過，可對照 Release 頁面的 `SHA256SUMS.txt`。

開啟後會跳出一個獨立視窗（使用系統上的 Edge 或 Chrome，找不到就用預設瀏覽器）。這個畫面只有你的電腦連得到。關閉視窗大約 2 分鐘後程式會自動結束，也可以按左下角「結束程式」。

## 2. 匯出聊天記錄

**LINE**：聊天室右上角 ≡ → 設定 → 傳送聊天記錄 → 存成 `.txt`。建議用電腦版匯出。

**Instagram**：帳號中心 → 你的資訊和權限 → 匯出你的資訊 → 訊息，格式選 **JSON**。把資料夾裡所有 `message_*.json` 一起選取。

同一個人在兩個平台都聊過：兩種檔一起選，並在「合併兩個平台的名字」填 `IG名=LINE名`。

## 3. 開始分析

1. 在「開始分析」頁，把檔案拖進來，或按選檔。
2. 視需要填寫選項：

| 欄位 | 什麼時候用 |
|---|---|
| 你的名字 | 填聊天室裡顯示的名字，讓結果標示「你」。 |
| 排除機器人或系統帳號 | 有機器人或官方帳號混進來時填，多個用逗號分開。 |
| 合併兩個平台的名字 | 格式 `IG名=LINE名`。 |
| 只分析從／到（不含當天） | 只看某段期間。例如只看最近 8 到 12 週。 |
| 時區 | 台灣是 8。 |

3. 按「開始分析」。通常幾秒到幾十秒。

## 4. 怎麼看結果

**總覽**
- 親密度（0–100）、浪漫訊號（0–100）、關係區間、趨勢（升溫／持平／降溫）、**信心（高／中／低）**。
- 五維度：互惠、回應、投入、溫度、穩定。
- **健檢警告**：機器人、資料太短、單日爆量、回覆速度不可用、疑似結構化對話。出現這些時信心會自動降為「低」。
- 每個指標都附證據，可展開看原始統計。

**未來預測**
- 未來 8 週的訊息量走勢（有區間）和五種落點的相對可能性。
- 這是**情境模擬，不是預言，也不是真實機率**。請看排序和區間寬度，不要看單一百分比。

**圖表**：十多張圖，點擊可放大。圖是 SVG，由瀏覽器繪製。

**匯出**：「下載全部結果」會打包統計、分數、預測、圖表和 `scorecard.json`。

## 5. 歷史紀錄：儲存、前後比對、回測

**選儲存位置**：在「開始分析」頁最下方按「選擇資料夾…」，或用預設位置（文件夾裡的 `ChatRelationshipReport`）。選好後，每次分析完會自動存一筆。要暫停可取消勾選「每次分析完自動存入歷史紀錄」。

**存了什麼**：統計數字、分數、預測、圖表和你填的備註。**不存聊天原文**，也不存逐則明細，連「證據原文片段」都會移除。每筆紀錄是資料夾裡的一個子資料夾，直接用檔案總管或 Finder 就能複製、備份或刪除。

**怎麼用**
1. 每隔一段時間（例如每個月）匯出新的聊天記錄，再分析一次。建議用同一種設定（同樣的名字與時區）。
2. 到「歷史紀錄」分頁。同一段關係的紀錄會歸在一起，並畫出親密度的變化。
3. 勾選同一段關係的兩筆，按「比較勾選的兩筆」，會列出每個指標的前後變化。
4. 「開啟」可以重新查看當時的總覽、預測與圖表。

**同一段關係怎麼判斷**：用雙方的名字。名字改了（例如換了暱稱），會被當成不同的關係。

**預測準不準（回測）**
- **訊息量**：較早那次預測了未來幾週的訊息量，之後的紀錄已經涵蓋那幾週，就能比對實際。畫面會顯示：已驗證的週數、實際落在 80% 區間內的比例（理想約 80%）、中位數預測的平均誤差，並和「直接沿用近 4 週平均」這種簡單做法比較。
- **關係落點**：預測給的是主觀情境，程式不知道你們後來實際怎麼了。請在紀錄表的「實際狀態」欄標註你認為的真實狀態，且與預測相隔至少 6 週，才會開始比對。

**不會自動調整**：回測只量測，不會偷偷改權重。紀錄少的時候自動調整會過度貼合那幾次，反而更不準。累積到足夠多組之後，才有資格檢討預測用的權重。

**換電腦或重灌**：把儲存資料夾複製過去，在新電腦選同一個資料夾即可。

## 6. 常見問題

**分數看起來偏低？** 只看文字，電話與見面看不到，所以分數是下限估計。

**信心是「低」怎麼辦？** 通常是資料不到 14 天、訊息集中在少數幾天，或對話由輪流發問這類規則帶動。換更長的資料，或用「只分析從」避開爆量期。

**說「沒有預測」？** 需要至少 8 週資料，而且只適用二人聊天。

**會不會上傳？** 不會。程式只在本機運行，介面只對本機開放，並用一次性金鑰保護。歷史紀錄只存在你選的資料夾，請自行決定要不要放在雲端同步資料夾。

**解析失敗或名字怪怪的？** 不同語系或舊版 LINE 的匯出格式可能不同。請用匿名化後的一小段範例回報。**不要把聊天記錄貼到公開的地方。**

## 7. 限制（請務必看）

- 只看文字，不看語氣、表情包以外的內容、電話與見面。
- 門檻是經驗設定，沒有用大樣本校準，不要說「超過 X% 的人」。
- 未來落點是手設權重的啟發式分數，沒有用真實關係結果驗證。
- 看不出性別與血緣：兄弟、姊妹、閨蜜統稱「摯友」，家人關係需本人確認。
- 不做臨床診斷或依附型態標籤。這是自我觀察與娛樂，不是心理或醫療建議。
